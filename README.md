# QQ 表情包提取与去重

一个在本机运行的 Python 图形界面工具，提供 QQ 表情包提取、多文件夹重复检测和一键去重。

## 启动

Windows 安装 **Python 3.10 或更新版本**，安装时启用 Tcl/Tk，并勾选 **Add Python to PATH**。

使用打包版时，从 [GitHub Releases](https://github.com/Jeatricy/QQ_Emoji_Extraction/releases/latest) 下载 `QQEmojiExtraction.exe`，双击即可，无需另行安装 Python。本地已打包的程序位于 `dist/QQ表情包提取.exe`。

使用源码时，双击同目录下的 **`启动.bat`** 即可。脚本首次运行会在程序目录创建 `.venv` 虚拟环境，并联网安装 CustomTkinter、Pillow 和 Send2Trash；后续直接打开界面。表情包处理在本地完成。

也可以在本目录的 PowerShell 中手动执行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe .\qq_emoji_tool.py
```

如果 `python` 命令不可用而 `py` 可用，第一行改为 `py -3 -m venv .venv`。

## 提取表情包

1. 打开“提取表情包”页，工具会自动查找当前 Windows 用户的“文档 / Tencent Files”，也会考虑文档目录重定向及常见 OneDrive 文档位置。
2. 在列表中选择 QQ 账号。只显示已找到本地文件的表情库；QQ 账号来自本地数字目录名。
3. 选择导出文件夹，或直接在输入框中填写一个新的文件夹路径。
4. 点击“开始提取”。完成后可点“打开导出文件夹”。

支持的主要目录结构与你提供的路径一致：

```text
C:\Users\<用户名>\Documents\Tencent Files\<QQ号>\nt_qq\nt_data\Emoji\personal_emoji\Ori
```

如果 QQ 数据保存在其他磁盘，点击“选择数据目录”，选择对应的 `Tencent Files` 文件夹。也可以选 QQ 账号目录，或者直接选 `personal_emoji` 下的 `Ori` 文件夹。该工具检测本机磁盘中已经存在的文件，不会下载尚未缓存的 QQ 云端表情。

提取规则：

- 复制表情库里的所有普通文件到导出目录，只将扩展名统一改成 `.gif`，文件名其余部分不变。
- 例如 `00A62A51FAF2AA588E51043DE014CF27.jpg` → `00A62A51FAF2AA588E51043DE014CF27.gif`。
- 不改动源表情库，也不重新编码图片。改后缀并不等于格式转换：如果原内容本身是 GIF，动图内容会完整保留；如果原内容确实是 JPEG，它仍然是 JPEG 数据。
- 子文件夹结构会一并保留。
- 输出位置已存在同名文件时自动跳过，不覆盖，也不追加数字修改原名。即使两份内容不同，只要目标路径同名也会跳过；详情见“操作记录”。
- 源目录与导出目录不能相同，也不能互相包含。
- 取消任务时，已完成的副本保留；正在复制且未完成的副本会尝试清理。

## 查找并清理重复文件

1. 打开“查找重复文件”页，点击“添加文件夹”逐个加入目录；也可以用“批量添加路径”一次粘贴多个目录，每行一个完整路径。只添加一个目录也能查找内部重复。
2. 用列表中的 ↑ / ↓ 调整保留优先级。默认每组保留最靠前文件夹中的一份；同一文件夹内按相对路径排序。也可以在扫描结果中为每组单独指定“保留此份”。
3. 根据需要勾选“包含子文件夹”（默认开启），点击“扫描重复文件”。所有普通文件按完整内容计算 SHA-256，不按文件名或扩展名筛选。
4. 查看重复组、缩略图以及每份副本的完整路径。每组会标明“文件夹内重复”“跨文件夹重复”或“跨文件夹及文件夹内重复”，并列出各文件夹的副本数量。
5. 点击“一键去重（每组留一份）”，核对确认窗口后，将所有重复组中未指定保留的副本移入回收站。此操作覆盖所有页。
6. 需要只清理部分副本时，调整“删除”复选框，点击“删除勾选项（回收站）”。

选择与预览：

- **保留副本**：“保留此份”单选按钮为每组指定唯一保留文件，该文件的“删除”复选框不可用。改选保留副本时，原保留文件成为可清理副本。
- **多选**：勾选多个文件，翻页后保留位置及勾选状态不变。扫描完成后默认勾选各组的多余副本。
- **一键全选**：“全选多余副本”会选中全部重复组中未指定保留的副本，包括未显示的页面。
- **一键取消**：“取消全选”清空当前勾选。
- **一键去重**：按各组指定的保留位置清理所有多余副本，不受当前页或手动勾选范围限制。
- 每页 12 个重复组，每组展示所有副本。点击缩略图或“预览及完整路径”可查看大图、完整 SHA-256、重复类型及所有副本路径。
- 图片和动图的缩略图及放大预览均展示首帧。预览根据实际内容识别格式，即使扩展名被改过也会尝试读取。
- 非图片或无法解码的文件显示“无法预览”，仍然参与内容比对及清理。

重复判定与删除行为：

- 按完整文件字节计算 SHA-256；不同文件名、不同扩展名但内容相同的文件会被归为同一组。
- 同一个目录内有两份相同内容，或不同目录之间有相同内容，都会列为重复组。例如 B 中有两份相同文件，即使其他目录完全没有该内容，也会显示，并可清理到只留一份。
- 重复添加同一个目录会自动忽略。同时选择父目录和子目录时，同一个文件路径只扫描、计数一次，不会因为扫描范围重叠产生虚假的重复。重叠范围内的文件归属最先覆盖该路径的列表目录。
- 视觉相同但重新压缩、修改元数据或转码过的图片，文件内容可能不同，不属于本工具的完全相同文件。
- 删除前重新核对待删文件的内容和状态，并检查该组指定保留副本的内容和状态。待删文件变化、保留副本丢失或变化时，跳过并记录原因。指定保留副本始终排除在清理计划外。
- 只把清理计划中的副本移入系统回收站；各组指定保留的文件和没有重复的文件保留。程序不会自动删除空目录。
- 回收站不可用、文件被占用或权限不足时记录失败，不改为永久删除。需要恢复时，可在 Windows 回收站中还原。
- 取消清理不会撤回已经移入回收站的文件；尚未处理的文件保留。
- 任务期间不能更改目录、保留位置或发起第二个文件任务。增加、移除、重排目录或改变递归选项会使上次结果失效。取消扫描后不展示不完整结果，需要重新扫描。
- 扫描时跳过符号链接和目录联接，避免把其他目录的文件混入所选范围。

“用导出目录去重”按钮可以将导出目录加入扫描列表；可以只扫描导出目录，也可以再加入已有的表情收藏一起去重。扫描列表和保留优先级会保存供下次启动使用，旧版 A / B 路径设置会自动迁移到列表。

## 文件与记录

| 文件 | 用途 |
| --- | --- |
| `启动.bat` | Windows 双击启动入口，首次准备独立环境 |
| `qq_emoji_tool.py` | Tkinter 中文图形界面、缩略图及后台任务调度 |
| `emoji_core.py` | QQ 账号发现、文件导出、SHA-256 比对及回收站清理 |
| `requirements.txt` | 第三方依赖 |
| `packaging/QQ表情包提取.spec` | 正式 Windows 单文件 EXE 打包配置 |
| `qq_emoji_settings.json` | 运行后生成，保存上次选择的目录 |
| `qq_emoji_tool.log` | 运行后生成，记录跳过、失败及删除结果；达到 2 MB 时滚动保存，保留两份历史日志 |

如双击后没有出现窗口，可按上面的 PowerShell 命令运行 `qq_emoji_tool.py` 查看错误，并查看 `qq_emoji_tool.log`。

依赖说明：[CustomTkinter](https://github.com/TomSchimansky/CustomTkinter) 提供现代化的圆角界面控件；[Pillow](https://pillow.readthedocs.io/en/stable/reference/Image.html) 用于识别图片及生成缩略图；[Send2Trash](https://github.com/arsenetar/send2trash) 用于将文件移入系统回收站。底层仍使用 Python 自带的 Tkinter。

## 界面

- 右上角可在 **浅色 / 深色** 两套配色之间实时切换，选择会写入 `qq_emoji_settings.json`，下次启动自动沿用。
- 顶部标签页切换「提取表情包」与「查找重复文件」，两项均显式使用 Microsoft YaHei UI、字号 14、常规字重，并随显示缩放调整，与中文界面字体保持一致。
- 账号列表、重复文件缩略图、进度条与提示均为圆角卡片式控件。
