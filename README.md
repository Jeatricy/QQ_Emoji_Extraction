# QQ 表情包提取与去重

一个在本机运行的桌面工具，用于从 QQ 本地数据中提取表情包，并在两个文件夹之间按内容清理重复文件。

界面基于 **CustomTkinter**，支持浅色 / 深色主题实时切换。

![提取表情包](界面预览/01-提取表情包-浅色.png)

## 运行方式

### 方式一：下载打包好的 exe（无需安装 Python）

到 [Releases](../../releases) 下载最新的 `QQEmojiExtraction.exe`，双击即可运行。

- 首次启动稍慢（单文件包需要自解压），属于正常现象。
- 程序会在 exe 所在目录生成 `qq_emoji_settings.json`（保存上次选择的目录与主题）和 `qq_emoji_tool.log`（运行日志）。

### 方式二：从源码运行

需要 Windows 上安装 **Python 3.10 或更新版本**，安装时启用 Tcl/Tk 并勾选 **Add Python to PATH**。

双击 `启动.bat` 即可。首次运行会在同目录创建 `.venv` 并联网安装依赖，之后直接打开界面。

也可以在 PowerShell 中手动执行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe .\qq_emoji_tool.py
```

如果 `python` 不可用而 `py` 可用，第一行改为 `py -3 -m venv .venv`。

> `启动.bat` 会自动识别并修复不可用的 `.venv`（例如从别的电脑拷贝过来、Python 路径已变化的环境），无需手动删目录。安装依赖时若网络中断会自动重试。

### 方式三：自己打包 exe

```powershell
.\.venv\Scripts\python.exe -m pip install pyinstaller
.\.venv\Scripts\python.exe -m PyInstaller --noconfirm --clean packaging\QQ表情包提取.spec
```

产物在 `dist\` 下。spec 中已收集 CustomTkinter 的主题与字体资源。

## 界面

- 右上角可在 **浅色 / 深色** 两套配色之间实时切换，选择会写入 `qq_emoji_settings.json`，下次启动自动沿用。
- 顶部标签页切换「提取表情包」与「查找重复文件」。
- 账号列表、重复文件缩略图、进度条与提示均为圆角卡片式控件。

## 提取表情包

1. 打开「提取表情包」页，工具会自动查找当前 Windows 用户的「文档 / Tencent Files」，也会考虑文档目录重定向及常见 OneDrive 文档位置。
2. 在列表中选择 QQ 账号。只显示已找到本地文件的表情库；QQ 账号来自本地数字目录名。
3. 选择导出文件夹，或直接在输入框中填写一个新的文件夹路径。
4. 点击「开始提取」。完成后可点「打开导出文件夹」。

支持的主要目录结构：

```text
C:\Users\<用户名>\Documents\Tencent Files\<QQ号>\nt_qq\nt_data\Emoji\personal_emoji\Ori
```

如果 QQ 数据保存在其他磁盘，点击「选择数据目录」，选择对应的 `Tencent Files` 文件夹。也可以选 QQ 账号目录，或者直接选 `personal_emoji` 下的 `Ori` 文件夹。该工具检测本机磁盘中已经存在的文件，不会下载尚未缓存的 QQ 云端表情。

提取规则：

- 复制表情库里的所有普通文件到导出目录，只将扩展名统一改成 `.gif`，文件名其余部分不变。
- 例如 `00A62A51FAF2AA588E51043DE014CF27.jpg` → `00A62A51FAF2AA588E51043DE014CF27.gif`。
- 不改动源表情库，也不重新编码图片。改后缀并不等于格式转换：如果原内容本身是 GIF，动图内容会完整保留；如果原内容确实是 JPEG，它仍然是 JPEG 数据。
- 子文件夹结构会一并保留。
- 输出位置已存在同名文件时自动跳过，不覆盖，也不追加数字修改原名。即使两份内容不同，只要目标路径同名也会跳过；详情见「操作记录」。
- 源目录与导出目录不能相同，也不能互相包含。
- 取消任务时，已完成的副本保留；正在复制且未完成的副本会尝试清理。

## 查找并清理重复文件

1. 打开「查找重复文件」页，选择文件夹 A 和文件夹 B。
2. 根据需要勾选「包含子文件夹」（默认开启）。两个目录不能相同或互相包含。
3. 点击「扫描重复文件」。工具会读取两个目录内的所有普通文件，为每个文件计算 SHA-256，不按文件名或扩展名筛选。
4. 扫描完成后，选择「文件夹 A（保留 B）」或「文件夹 B（保留 A）」。默认清理 B。
5. 查看重复文件缩略图，勾选要删除的文件。
6. 点击「删除勾选项（回收站）」，在确认窗口核对清理目录及数量后执行。

选择与预览：

- **单选**：只勾选一个文件的复选框。
- **多选**：勾选多个文件，翻页后勾选状态保留。
- **一键全选**：「全选所有页」会选中当前清理侧的全部重复文件，包括未显示的页面。
- **一键取消**：「取消全选」清空当前勾选。
- 切换清理侧会清空勾选，避免把上一侧的选择带到另一侧。
- 每页 24 个文件。点击缩略图可查看大图、完整路径、完整 SHA-256，以及另一侧所有相同文件的路径。
- 图片和动图的缩略图及放大预览均展示首帧。预览根据实际内容识别格式，即使扩展名被改过也会尝试读取。
- 非图片或无法解码的文件显示「无法预览」，仍然参与内容比对及清理。

重复判定与删除行为：

- 按完整文件字节计算 SHA-256；不同文件名、不同扩展名但内容相同的文件会被归为同一组。
- 只显示 **A 与 B 之间** 的重复内容。如果多份副本只存在于 A 内，而 B 中没有相同内容，则不显示。
- 视觉相同但重新压缩、修改元数据或转码过的图片，文件内容可能不同，不属于本工具的完全相同文件。
- 删除前重新核对待删文件的内容和状态，并检查另一侧至少还存在一份内容相同且可读取的文件。文件发生变化或另一侧副本消失时，跳过并记录原因。
- 只把所选一侧中勾选的文件移入系统回收站；另一侧保留。程序不会自动删除空目录。
- 回收站不可用、文件被占用或权限不足时记录失败，不改为永久删除。需要恢复时，可在 Windows 回收站中还原。
- 取消清理不会撤回已经移入回收站的文件；尚未处理的文件保留。
- 扫描期间不能切换目录或发起第二个文件任务。取消扫描后不展示不完整结果，需要重新扫描。
- 扫描时跳过符号链接和目录联接，避免把其他目录的文件混入所选范围。

「用导出目录去重」按钮可以将导出目录填入文件夹 B；再选择一份已有的表情收藏作为 A 即可比较。

## 文件与记录

| 文件 | 用途 |
| --- | --- |
| `启动.bat` | Windows 双击启动入口，首次准备独立环境 |
| `qq_emoji_tool.py` | CustomTkinter 中文图形界面、缩略图及后台任务调度 |
| `emoji_core.py` | QQ 账号发现、文件导出、SHA-256 比对及回收站清理 |
| `requirements.txt` | 第三方依赖 |
| `packaging/QQ表情包提取.spec` | PyInstaller 打包配置 |
| `qq_emoji_settings.json` | 运行后生成，保存上次选择的目录与主题 |
| `qq_emoji_tool.log` | 运行后生成，记录跳过、失败及删除结果；达到 2 MB 时滚动保存，保留两份历史日志 |

依赖说明：[CustomTkinter](https://github.com/TomSchimansky/CustomTkinter) 提供现代化的圆角界面控件；[Pillow](https://pillow.readthedocs.io/en/stable/reference/Image.html) 用于识别图片及生成缩略图；[Send2Trash](https://github.com/arsenetar/send2trash) 用于将文件移入系统回收站。底层仍使用 Python 自带的 Tkinter。

## 测试与审查

- 界面功能回归 **33 项通过**：账号渲染与选择、分页、勾选与全选、清理侧切换、主题切换与持久化、任务期间锁定与解锁、缩略图上屏、参数变更使结果失效。
- 端到端流程 **26 项通过**：真实后台线程扫描、SHA-256 分组、缩略图渲染、真实移入 Windows 回收站、日志与设置落盘；并覆盖了「内容相同但无法解码」的文件。
- 打包产物已验证可在未安装 Python 的环境独立启动；`启动.bat` 的失效环境自动重建、依赖安装断线重试均已实测。

需要检查运行环境时，可在 PowerShell 中执行：

```powershell
.\启动.bat --check
.\.venv\Scripts\python.exe -m pip check
```
